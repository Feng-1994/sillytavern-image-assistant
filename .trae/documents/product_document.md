## 1. 产品概述

STA（SillyTavern Android）是专为移动端用户设计的 SillyTavern 原生增强客户端，旨在提供与 Web 版完全对等的用户体验，同时针对手机操作场景进行深度优化。本项目为 STA 的移动端 Web 应用实现（PWA），采用 React + TypeScript 构建，忠实还原交互原型的 UI/UX 设计，可作为独立 PWA 运行，也可通过 Capacitor 封装为原生 Android 应用。

- 解决移动端用户访问 SillyTavern 时连接不稳定、缺乏推送通知、语音输入受限等痛点
- 目标用户：SillyTavern 现有重度用户、技术爱好者、追求隐私安全的 self-hosted 用户

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|---------|---------|
| 普通用户 | 连接自建 SillyTavern 服务器 | 浏览和使用全部聊天、角色、设置功能 |

### 2.2 功能模块

1. **连接页**：服务器发现与连接管理，支持局域网自动发现、远程隧道连接
2. **聊天页**：AI 对话核心界面，流式输出、消息操作、角色表情
3. **侧边栏**：导航抽屉，包含用户信息、对话列表、管理入口
4. **角色库**：角色卡片网格浏览、搜索过滤、分类标签
5. **群聊页**：多角色群聊界面，成员管理、@提及
6. **设置页**：分组设置项，连接/聊天/移动端增强/外观配置

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深色背景 #12121a，紫色强调色 #7c3aed（SillyTavern Purple）
- **辅助色**：蓝色 #2563eb、绿色 #059669、红色 #ef4444
- **按钮样式**：圆角 12-16dp，紫色填充主按钮，边框次要按钮
- **字体**：系统字体栈 -apple-system, SF Pro Display, Segoe UI, Roboto
- **字号层级**：标题 22sp/600、正文 14sp/400、辅助 12sp、元数据 10sp
- **布局风格**：移动端优先，底部导航 + 侧边抽屉，卡片式布局
- **图标风格**：Emoji 图标 + Lucide 线性图标混合使用
- **动效**：cubic-bezier(0.2, 0, 0.2, 1) 缓动曲线，脉冲动画、滑入动画、打字指示器

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|---------|---------|---------|
| 连接页 | 问候区域 | 居中 Logo emoji、22sp 标题、13sp 副标题，深色背景 |
| 连接页 | 服务器卡片 | 圆角 12dp 卡片，图标+名称+地址+状态指示灯，悬停紫色边框 |
| 连接页 | 扫描条 | 脉冲圆点动画 + 扫描文字，深色背景条 |
| 聊天页 | 消息气泡 | 用户紫色气泡右对齐，AI 深色气泡左对齐，16dp 圆角 |
| 聊天页 | 表情栏 | 28dp 圆形表情 + 10sp 情绪标签胶囊 |
| 聊天页 | 输入栏 | 20dp 圆角输入框，聚焦紫色边框，圆形发送按钮 |
| 侧边栏 | 抽屉面板 | 280dp 宽，从左侧滑入，分区菜单项 |
| 角色库 | 角色卡片 | 双列网格，3:4 图片比例，14dp 圆角，悬停上浮 |
| 群聊页 | 成员横条 | 横向滚动，40dp 圆形头像，活跃紫色边框 |
| 设置页 | 设置项 | 分组列表，12dp 圆角项，Toggle 开关，紫色激活态 |

### 4.3 响应式设计

- **移动优先**：所有 UI 按 375×812 基准设计，最小触控区域 48dp
- **单手操作**：常用操作按钮位于屏幕下半部分
- **平板适配**：768px 以上切换为侧边栏常驻布局
- **触摸优化**：所有可交互元素有明确的触摸反馈（hover/active 状态）
